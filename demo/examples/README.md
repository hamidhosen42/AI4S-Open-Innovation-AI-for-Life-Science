Example images from the held-out test well (R05-C03, field 3) of the HeLa "Kyoto" dataset
(Romain Guiet, EPFL PTBIOP; Zenodo 10.5281/zenodo.6140064; CC BY 4.0).
`*_bf_*.tif` are bright-field inputs for the demo; `*_h2b_real_*.tif` are the matching real
H2B fluorescence images, provided only for visual comparison.
