১. এক নজরে কৌশল

ফাইনালে যাওয়া প্রায় নিশ্চিত (৬ টিম, ২০ স্লট) — তাই লক্ষ্য পুরস্কার। রুব্রিকের ৬০% আসে "সমস্যা গুরুত্বপূর্ণ কি না" + "মেথড নতুন কি না" থেকে। Bright-field → fluorescence আয়োজকের নিজের ঘোষিত impact area, তাই প্রথম ৩০% নিয়ে তর্ক নেই। দ্বিতীয় ৩০%-এর জন্য আমাদের অবদান: uncertainty-aware prediction — মডেল শুধু ফ্লুরোসেন্স না, কোথায় সে ভরসাযোগ্য নয় সেটাও বলে দেয়। এটা বায়োলজিস্টের বাস্তব দরকার, আর জাজদের "interpretability" প্রশ্নের সরাসরি উত্তর।

নিয়ম: একটা জিনিস পুরোপুরি শেষ করা > তিনটা জিনিস অর্ধেক। প্রতিটা সপ্তাহের শেষে একটা "জমা দেওয়ার মতো" অবস্থা থাকবে — সপ্তাহ ১-এর শেষেই বেসলাইন + মেট্রিক + রিপোর্ট আউটলাইন।

৪. প্রজেক্ট স্পেসিফিকেশন

InputBright-field / phase-contrast ইমেজ (single channel, 256×256 patch)
ModelU-Net, pretrained encoder; আউটপুট হেড: μ (fluorescence) + log σ² (uncertainty)
Outputপ্রেডিক্টেড fluorescence (nuclei) + per-pixel confidence map
EvalSSIM · PSNR · Pearson · segmentation F1 · calibration (σ vs |error|)
Problem
ব্রাইটফিল্ড থেকে নিউক্লিয়ার স্টেইন (DAPI/Hoechst) প্রেডিক্ট করা — স্টেইনিং ছাড়াই live OoC কালচারে সেল কাউন্ট, viability, morphology বিশ্লেষণ সম্ভব করা।
Data
প্রথম পছন্দ: পাবলিক paired brightfield+nuclear ডেটাসেট (Allen Cell label-free, JUMP-CP brightfield চ্যানেল, অথবা Zenodo/IDR-এর paired সেট)। সেকেন্ডারি: একটা ভিন্ন সেল-লাইন/ইমেজিং সেটে zero-shot টেস্ট = "OoC transfer" যুক্তি। সব লাইসেন্স DATA.md-এ।
Baseline
Plain U-Net, L1 loss। এটাই "তুলনার বেসলাইন"।
Ours
(a) ImageNet-pretrained ResNet34 encoder, (b) Gaussian NLL loss দিয়ে heteroscedastic uncertainty, (c) test-time augmentation। Ablation: a / a+b / a+b+c।
Metrics
SSIM, PSNR, Pearson r (image-level); Cellpose F1@IoU0.5 (downstream); Spearman(σ, |error|) + sparsification curve (calibration)।
Split
Experiment/plate-level hold-out (একই well-এর patch দুই দিকে যাবে না)। ৩ seed, mean ± std রিপোর্ট।
Demo
Gradio অ্যাপ → Hugging Face Spaces (CPU, free)। আপলোড → ৩ প্যানেল: input / predicted / uncertainty। ব্যাকআপ: স্ক্রিনশট + লোকাল রান নির্দেশনা।
Compute
লোকাল Apple M5 (MPS) ছোট ডেটায়; বড় রান Kaggle T4/P100 নোটবুক (ফ্রি, সপ্তাহে ৩০ ঘণ্টা)।

স্কোপ সীমা: শুধু একটা টার্গেট চ্যানেল (nuclei)। একাধিক চ্যানেল, 3D, বা নিউরাল ডেটা — শুধু যদি সপ্তাহ ২-এর মাঝামাঝি সব শেষ থাকে, নইলে "Future work"।
