# ChipStain — live demo recording script (target 4:30, hard limit 5:00)

Generated by `scripts/build_writeup.py` from the current results — every number below matches the report.
Record the screen with **QuickTime** (File → New Screen Recording) or **Loom**, 1080p, with your own voice.
Structure: slides 1–3 → **live demo (replaces slides 4–5) (the part judges care most about: the real system running)** → slides 6, 8, 9, 10 (slide 7, the shift plot, is skipped — the demo already covers it).

## Before you press record (5 minutes)

1. Open a terminal in the project folder and start the demo:
   ```bash
   python demo/app.py --weights weights/chipstain.pt
   ```
   Wait for `Running on local URL: http://0.0.0.0:7860`, then open **http://localhost:7860** in Chrome.
2. Do one **warm-up run** (click the first example → Predict) so the first prediction in the video is fast.
3. Open `writeup/ChipStain_slides.pdf` full-screen in Preview (View → Slideshow), on slide 1.
4. Close notifications (Do Not Disturb), other tabs and windows. Browser zoom 100–110 %.
5. Make sure **"Test-time augmentation"** is ticked in the demo.

Demo files (inside `demo/examples/`, also listed as clickable examples under the app):
- `example_bf_dense_t150.tif` — clean bright-field, held-out well
- `example_bf_dense_t150_blur1px.tif` — the same image blurred by 1 px
